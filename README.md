# CZCBF-MPC-SF

This repository hosts the official code release for the paper:

**Safe Navigation among Polytopes: A Hierarchical Constrained Zonotope-Based Control Barrier Function Approach**

by **Jinyang Dong, Shizhen Wu, Hao Guo, Hai Yu, Yongchun Fang**.

## Status

The source code, simulation environments, and reproduction scripts are being prepared for public release.

The repository will be open-sourced after the paper review process is complete. Please check back later for:

- 2D CZCBF-MPC-SF simulations
- 3D CZCBF-MPC-SF simulations
- ROS/Gazebo Jackal simulation demo
- Instructions for reproducing the figures and benchmark results
